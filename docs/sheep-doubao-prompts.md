用途：把本文件里的提示词逐段复制给豆包（建议用「图生图 / 参考图」模式，先上传 `design/reference-original.png`）。
分工：**豆包只负责出图**。切帧、缩档、锚点对齐、透明化由我们的脚本处理，不用豆包管。

## 通用规则（每张图都要遵守）

**背景**：纯 #00FF00 荧光绿幕，铺满整张，**不要**渐变、不要地面线、不要投影落地、不要文字、不要边框、不要水印。
**画幅**：正方形 1:1。
**构图**：角色全身完整居中，不裁切耳朵、尾巴、四肢；角色高度约占画面 65–70%，脚底落在画面同一水平位置（下方留白约 18%）。

### 风格前缀（贴在每段提示词开头）

```
2D平面插画，体积感非常轻微克制：只用柔和浅色渐变轻轻暗示圆润，明暗约2-3层（底色、浅暗部、深暗部），阴影柔和低对比。不要强烈3D渲染、不要Pixar厚重体积、不要油亮球面高光、不要深重暗部、不要扁平矢量贴纸感、不要粗黑描边。低饱和奶油色系（莫兰迪）。浅棕色细描边，外轮廓与内部结构线都描边，线条细而均匀。

角色是一只小羊羔：羊毛奶白色偏暖黄，暗部浅灰卡其偏暖；脸与羊毛同色但更平滑、无暗部；手脚深棕色；鼻子浅粉色。
头顶羊毛由多个云朵状半圆团堆叠，边缘有凹陷缺口分团，内部有顺毛流走向的弧形线和短波浪线；额头中央有一团带粗螺旋线的卷（约1.5圈）；羊毛与脸的分界是波浪形花边。
眼睛竖椭圆纯黑，内有纯白圆点高光：大的在10点钟方向，小的在4点钟方向。鼻子很小、圆润倒三角、浅粉。嘴是一条单线ω形、中间略粗两端细、嘴角朝上。腮红是渐变浅粉圆斑，在眼睛下方偏外侧。
身体鸡蛋/水滴形，上窄下宽，肚子圆润。耳朵是横向长椭圆。四肢极短，深棕色末端占肢体长度约1/4，深色区上沿是平直横线，末端完整光滑无缝、无脚趾趾缝、无蹄壳裂缝。
全身无眉毛、无任何服装帽子领带领结徽章工牌logo。
```

## 一、游戏运行必需（5 张，优先做）

### 图1 — 跑步第1帧（背面）

```
【风格前缀】+ 以下

【视角】纯背面，第三人称追尾后视，正对角色后背，完全看不到脸、看不到五官、看不到鼻子和眼睛。这是游戏里玩家追在羊后面的视角。

【本帧姿势】右后腿支撑着地、承重；左后腿抬起向后蹬，膝盖略弯。躯干轻微上浮。

【背面细节】后脑勺由多团云朵状羊毛组成，耳朵从后脑两侧横伸出来（只看得到耳背，不要画粉色内耳）。脖颈处有一圈波浪形羊毛分界线。尾巴是一个圆球状、约头宽18%大小、长在臀部正中央偏上，完整可见。身体躯干相对平滑、只有波浪纹理，不要画成独立卷团。
```

## 二、设定表参考（可选，不影响游戏运行）

游戏是追尾后视，玩家看不到羊脸，所以**以下 5 张对游戏画面没有任何影响**，只在做宣传图、周边、设计规范时需要。

### 图6 — 正面全身（已有 v2 候选，可重出）

```
【视角】正面全身，正对镜头。身体向画面左侧轻微侧转约15度（不完全正对）。两只耳朵不完全对称：画面左侧耳朵略微向下垂，画面右侧耳朵略微向外平伸。

【姿势】两条后腿承重着地、笔直；两条前臂从脖子下方、身体最窄处伸出，与身体之间有明显缝隙（不紧贴），笔直向下垂、末端朝下。前臂很短，末端自然悬在半空、不接触地面。

【禁忌】前腿不要举到胸前、不要抱在胸口、不要弯折。
```

### 图7 — 四分之三视图

```
【视角】四分之三侧视（约左前方45度），能看到脸的正面和一部分侧面，全身完整。
【姿势】同图6：两后腿着地，两前臂从身体两侧笔直下垂、末端悬空。
```

### 图8 — 严格侧面

```
【视角】严格正侧面90度，正对角色左侧，只能看到一只眼睛、一只耳朵、一侧轮廓，另一侧完全被身体挡住。不要任何3/4角度、不要能看到两只眼睛。
【姿势】同图6：两后腿着地，两前臂笔直下垂、末端悬空。
```

> 这张是难点：文生图模型极容易画成 3/4。如果连续几次都不准，建议直接用图生图+人工裁改，或者放弃这张。

### 图9 — 背面设定

```
【视角】纯背面全身，零五官。后脑羊毛团、耳朵背面、尾巴居中、围脖波浪分界线。
【姿势】直立站姿：两条后腿着地，两条前臂从身体两侧伸出、笔直下垂、末端悬空。
```

### 图10 — 表情集

```
【要求】四宫格2×2，同一只羊、同一正面角度、同一大小，只改表情：
左上=平静（眼睛正常睁开、嘴平）
右上=开心（眼睛弯成上弧、嘴角明显上扬）
左下=惊讶（眼睛放大变圆、嘴张成小圆）
右下=受伤（眼睛变成 >< 或紧闭成横线、嘴咧开）
每格都是正面头部，不含身体，纯绿幕背景，格与格之间留白。
```
